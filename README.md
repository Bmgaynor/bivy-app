# Bivy

Backcountry weather answers by text message. Text `lat,lon | question` to Bivy's
number (it works over satellite SMS) and get a short forecast answer back, written
by Claude from live weather data. A small installable composer app builds the text
for you.

- Live site and composer: https://bradgaynor.com/bivy-app/index.html
- [`CLAUDE.md`](CLAUDE.md): architecture, commands and deployment
- [`docs/FEATURES.md`](docs/FEATURES.md): how to build new features
- [`satellite-weather-assistant-plan.md`](satellite-weather-assistant-plan.md): the phased plan

This is a personal project: replies only go to an approved list of numbers.
